CASE 02 / MICROSERVICES · LLM FINE-TUNING

서비스의 역할을 해석해 요구사항에 맞게 연결하다

Kubernetes 명세에서 서비스의 기능·연결 요소를 분석하고, BCE 패턴과 LLM Fine-tuning을 서비스 선택·약결합 배포에 적용했습니다.

Project context

ROLE

SELab 연구원 · 명세 분석, 학습 방법 설계 및 프로토타입 구현

PROJECT

  • 컨테이너 기반 마이크로서비스 개발을 위한 스마트 프레임워크 기술한국연구재단(NRF) · 2024.03–2026.01
배경담당한 일기술적 접근검증과 범위Resources

CONTEXT

어떤 문제를 다뤘나요?

기존 마이크로서비스를 조합하려면 각 서비스의 기능과 연결 관계를 이해해야 합니다. 사용자 요구사항에서 필요한 서비스를 찾고 연결·배포할 수 있도록, 명세 분석과 배치 유형 식별 방법을 연구했습니다.

MY CONTRIBUTION

직접 담당한 일

01

명세에서 기능·연결 요소 도출

Kubernetes YAML의 Pod·Service·Deployment 명세를 분석하고, 서비스 기능과 약결합에 필요한 요소를 구조화했습니다.

02

BCE 패턴을 학습 기준으로 사용

Boundary·Control·Entity 패턴을 바탕으로 서비스의 역할과 배치 유형을 구분했습니다. 마이크로서비스 명세와 패턴 유형을 연결한 학습 데이터를 구성하고 LLM Fine-tuning 방법을 설계·검증했습니다.

03

선택에서 약결합 배포까지 연결

사용자 기능 요구사항에 적합한 마이크로서비스를 추천하고, 선택한 서비스를 약결합하여 배포하는 프로토타입을 구현·검증했습니다.

APPROACH

역할 구분을 서비스 조합의 기준으로

서비스의 이름만으로 조합을 결정하기보다 명세에서 도출한 기능과 BCE 패턴의 역할을 함께 사용했습니다. 서비스 선택에 필요한 구조적 정보를 LLM이 학습할 수 있는 형태로 정리한 접근입니다.

VALIDATION & SCOPE

검증과 결과의 범위

배치 유형 식별을 위한 학습 방법을 비교하고, 사용자 요구사항 기반 약결합 배포 사례를 통해 제안 방법을 검증했습니다. 관련 제1저자 논문은 ACK 2024 ETRI 원장상을 수상했으며, 연구 결과는 학술지 논문과 공동 특허 출원으로 이어졌습니다.

RAG 오류 식별 연구와 동일한 NRF 과제에서 수행한 또 하나의 기술 주제입니다. 학술 논문과 특허는 이 연구의 결과물로 연결했습니다.
