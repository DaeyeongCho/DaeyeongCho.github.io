CONTEXT

어떤 문제를 다뤘나요?

클라우드마다 자원의 명칭·식별자·제공 사양이 달라 운영에 필요한 정보를 비교하고 활용하기 어렵습니다. 두 ETRI 과제에서 메타데이터 탐색과 AI 가속기 자원 추천·인프라 구성이라는 서로 다른 운영 문제를 다뤘습니다.

MY CONTRIBUTION

직접 담당한 일

01

메타데이터 분류·검색 도구 · 2024.11–2025.03

클라우드 리소스 메타데이터와 VM 생성 워크로드의 기능 간 의존성을 분석했습니다. 리소스·식별자·메타데이터를 구분한 데이터베이스 스키마와 UML 기반 시스템을 설계하고, Go·React 프로토타입을 구현했습니다. JMeter를 활용해 기능·성능을 검증했습니다.

02

AI 가속기 추천과 인프라 구성 · 2025.09–2026.01

AWS·Google Cloud의 AI 가속기와 Managed Kubernetes 제공 현황을 수집·분석했습니다. 요구사항 입력을 위한 JSON 구조와 AHP 기반 추천 방법을 정립하고, 정보 수집·추천·인프라 구축 및 Prometheus·Grafana 모니터링 배포 스크립트를 구현했습니다.

APPROACH

정보 모델을 먼저 정리하고 도구로 구현

메타데이터 도구에서는 리소스와 식별자, 속성 정보를 구분해 저장 구조를 설계했습니다. AI 가속기 연구에서는 요구사항 항목을 정의한 뒤 JSON 입력과 추천 방법으로 연결했습니다. 두 과제 모두 서로 다른 자원 정보를 활용 가능한 구조로 정리하는 데 중점을 뒀습니다.

VALIDATION & SCOPE

검증과 결과의 범위

메타데이터 도구는 기능·성능 테스트로 프로토타입을 검증했습니다. AI 가속기 과제에서는 추천 방법과 배포 자동화 스크립트를 구현했습니다. Cloud-Barista 활용 중 발견한 Postgres 접근 오류는 발생 조건·재현 절차·해결 과정을 공개 이슈로 보고했습니다.

두 과제의 담당 범위와 기술을 구분했습니다. Azure 경험은 멀티 클라우드 메타데이터 영역에 해당하며, AI 가속기 조사·추천은 AWS·Google Cloud를 중심으로 수행했습니다.
