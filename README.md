## 🔬 Research

### 🧩 마이크로서비스 배치 및 사용자 요구사항 맞춤형 약결합 배포

Kubernetes 명세(YAML)에서 마이크로서비스의 기능 및 약결합 요소를 분석하고,
**BCE(Boundary-Control-Entity) 패턴과 LLM Fine-tuning을 활용해 배치 유형을 식별하는 방법**을 연구했습니다.
이후 사용자 요구사항에 맞는 마이크로서비스를 선택하고 약결합하여 배포하는 방법으로 확장했습니다.

**주요 내용**
- Kubernetes Pod / Service / Deployment 기반 기능·약결합 명세 분석
- BCE 패턴 기반 Boundary / Control / Entity 유형 분류
- GPT-3.5-turbo Fine-tuning 기반 마이크로서비스 배치 유형 식별
- 사용자 요구사항 기반 마이크로서비스 추천 및 약결합 배포

**관련 연구**
- 「생성형 AI를 적용한 컨테이너 기반의 마이크로서비스 배치 기법」
- 「BCE 패턴 기반 마이크로서비스 아키텍처의 배치 유형 식별을 위한 생성형 AI 파인튜닝 방법」
- 「BCE 패턴 학습에 기반한 사용자 요구사항 맞춤형 마이크로서비스 약결합 배포 방법」

### 🔎 RAG 기반 컨테이너 마이크로서비스 오류 식별

컨테이너 기반 마이크로서비스의 **배포 및 약결합 과정에서 발생하는 오류를 운영 정보로 식별하고,
RAG와 LLM을 활용해 오류 해소 방안을 생성하는 방법**을 연구했습니다.
Kubernetes의 운영 정보와 Jaeger의 통신 흐름을 정상 상태와 비교하고, 기존 사례를 RAG 지식 베이스로 활용했습니다.

**주요 내용**
- 컨테이너 기반 마이크로서비스의 배포·약결합 오류 유형 도출
- Kubernetes 운영 정보 및 Jaeger 기반 통신 흐름 수집·분석
- LangChain + ChromaDB 기반 RAG 지식 베이스 구축
- LLM 기반 오류 식별 및 해소 방안 생성·비교 평가

**관련 연구**
- 「RAG를 적용한 컨테이너 기반 마이크로서비스 배포 오류 식별 및 해소 방법」
- 석사학위논문 「RAG를 적용한 컨테이너 기반 마이크로서비스의 오류 식별 방법」
